# WAR & MACRO RADAR // Global Trading News Terminal

Institutional-grade real-time trading terminal designed to monitor **geopolitical flash events (US-Iran war, missile strikes, Middle East conflicts)** alongside **scheduled macroeconomic releases (CPI, FOMC, NFP, GDP)** with instant trade position playbooks and background audio/desktop alerts.

---

## ⚡ Quick Start (1-Click Run)

1. Double-click **`run.bat`** inside this folder.
2. It will open directly in Google Chrome.
3. Click the green button: **`🔔 ENABLE DESKTOP ALERTS`** at the top right.
4. Click **`🚨 TEST US-IRAN WAR FLASH`** to test the siren, positioning modal, and desktop notification!

---

## 🎯 Key Features & Modules

### 1. 🚨 War & Geopolitical Crisis Radar
- **Fast-scans live headlines** for critical triggers:
  `War`, `Iran`, `Israel`, `Missile`, `Strike`, `Attack`, `Explosion`, `Strait of Hormuz`, `Nuclear`, `Retaliation`, `Red Sea`, etc.
- **Red Alert Siren**: Plays an institutional oscillating dual-tone emergency siren via the Web Audio API.
- **Instant Trade Positioning Card**:
  - 🟢 **BUY / LONG GOLD (XAU/USD)**: Safe-haven capital rush.
  - 🟢 **BUY / LONG CRUDE OIL (BRENT/WTI)**: Persian Gulf / Hormuz supply risk premium.
  - 🟢 **BUY / LONG US DOLLAR (DXY)**: Global liquidity refuge.
  - 🔴 **SHORT / SELL S&P 500 & NASDAQ**: Risk-off equity liquidation.
  - ⚠️ **HIGH VOLATILITY BITCOIN (BTC)**: Flash selloff before stabilization.

### 2. ⏱️ Economic Calendar & CPI / FOMC Countdown
- Tracks major market drivers:
  - **US Core CPI** (Consumer Price Index)
  - **FOMC Rate Decisions** & Jerome Powell Press Conferences
  - **Non-Farm Payrolls (NFP)** & Unemployment Rate
  - **Core PCE Price Index** (Fed inflation metric)
  - **ECB & BoE Rate Decisions**
- Real-time countdown clock (Hours : Minutes : Seconds).
- **Automated Alert Stages**:
  - **15 Minutes Before**: Early warning chime.
  - **5 Minutes Before**: Urgent countdown beep.
  - **00:00 Release Moment**: High-impact release chime + notification.
- **Trading Playbook** (Click *"📖 TRADING PLAYBOOK"* on any card):
  - Explains what to trade if **Actual > Forecast** (Hot Inflation) vs **Actual < Forecast** (Cooling Inflation).

### 3. 🎯 Monitored Watchlist
- Add custom keywords to the radar (e.g. `Iran`, `Hezbollah`, `Taiwan`, `Gold`, `Fed`, `SEC`, `Oil`).
- Stored permanently in your browser via `localStorage`.

### 4. 🔔 Background Monitoring & Desktop Notifications
- Runs in background tabs or minimized browser windows.
- Windows OS will show native banner notifications with the trade advice so you never miss a breaking event while doing other work.

   - Right side par CPI aur FOMC ka live countdown chal raha hai.
   - 15 min pehle, 5 min pehle, aur theek time par alert aayega.
